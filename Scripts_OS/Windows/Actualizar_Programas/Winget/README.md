# Winget — actualizar programas

- `Upgrade Programas winget.bat`: actualiza todos los programas
  (`winget upgrade --include-unknown --all`). Función distinta a inventariar.
- El inventario de programas vive en `../../Inventario_Programas/`
  (`inventario_winget.bat` + menú).

## Uso

1. Clic derecho en `Upgrade Programas winget.bat` → **Ejecutar como
   administrador** (recomendado: varias apps solo se actualizan con
   elevación).
2. Espera a que termine y presiona cualquier tecla para salir.

## Requisitos

- Windows 10 1809+ / 11 con la herramienta `winget`.
