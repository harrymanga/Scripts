# Traducir_Archivos_TXT

Traducción de archivos `.txt` con Google Translate (googletrans).

## Uso

```bash
./run.sh        # GUI tkinter main2.py, con .venv automático (Linux/macOS)
```

En Windows: `run.bat`. (La antigua versión CLI `main.py` fue retirada por
rutas fijas inservibles; la GUI `main2.py` es la versión única.)
