# Traductor LANG (GUI Python)

Traductor de archivos `.lang` con GUI Tkinter, caché y limitador de ritmo.

## Uso

```bash
./run.sh        # crea .venv, instala dependencias y ejecuta (Linux/macOS)
```

En Windows: `run.bat`. (Equivalente manual: `python -m app.main`,
previa instalación de `requirements.txt`.)
