# Traducir_Archivos_PROPERTIES

Traducción de archivos `.properties` (DeepL / trans) con GUI Tkinter y
variantes Bash (ver `translate_properties_bash.sh` y
`translate_properties_multimotor.sh`, solo Linux).

## Uso

```bash
./run.sh        # GUI DeepL translate_properties_gui.py, con .venv (Linux/macOS)
```

En Windows: `run.bat`. Pendiente de consolidación en el grupo B.
