Chd_To_Cue.sh - Decompresses CHD (V5) to CUE.
The CUE format is used by CD-based games. CHD is supported by 3DO, Amiga CD32, Amiga CDTV, Dreamcast, Mega CD/Sega CD, Neo-Geo CD, PC Engine CD/TurboGrafx-CD, PlayStation et Saturn.

Chd_To_Gdi.sh - Decompresses CHD (V5) to GDI.
The GDI format is used by disc-based games for Dreamcast.

Chd_To_Iso.sh - Decompress CHD (V5) to ISO.
The ISO format is used by disc-based games for PlayStation 2.

Cue_To_Chd.sh - Compresses BIN disc format to CHD (V5). 
It will search all sub-folders and make CHDs in folder this is used in with CHDMAN.

Gdi_To_Chd.sh - Compresses GDI disc format to CHD (v5). 
The GDI format is used by disc-based games for Dreamcast.

Iso_To_Chd.sh - Compresses ISO disc format to CHD (V5). 
The ISO format is used by disc-based games for PlayStation 2.
