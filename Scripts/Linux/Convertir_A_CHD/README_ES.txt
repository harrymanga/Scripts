Chd_To_Cue.sh - Descompresión de CHD (V5) a CUE.
 El formato CUE es utilizado por juegos basados ​​en CD. CHD es compatible con 3DO, Amiga CD32, Amiga CDTV, Dreamcast, Mega CD/SEGA CD, Neo-Geo CD, PC Engine CD/TurbeGrafx-CD, PlayStation et Saturn.

Chd_To_Gdi.sh - Descomprime CHD (V5) a GDI.
 El formato GDI es utilizado por juegos basados ​​en discos para Dreamcast.

Chd_To_Iso.sh - Descompresión CHD (V5) a ISO.
 El formato ISO es utilizado por juegos basados ​​en discos para PlayStation 2.

Cue_To_Chd.sh - Comprime el formato de disco de BIN a CHD (V5). 
 Buscará todos los subcarpetas y hará CHD en la carpeta en la que se usa con Chdman.

Gdi_To_Chd.sh - Comprime el formato de disco GDI a CHD (V5). 
 El formato GDI es utilizado por juegos basados ​​en discos para Dreamcast.

Iso_To_Chd.sh - Comprime el formato de disco ISO a CHD (V5). 
 El formato ISO es utilizado por juegos basados ​​en discos para PlayStation 2.
